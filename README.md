# 仿生人剧情向游戏
> 一款围绕仿生人主题的剧情向独立游戏，目前版本制作较为简陋，仍在打磨中……

## 游戏简介
本作以**仿生人是否能够真正觉醒**、**人类与机器人的边界与区别**作为命题展开故事。
游戏采用多结局叙事设计，不同的选择将会导向完全不一样的故事走向，剧情之中内嵌多款小游戏，在游玩过程中推进人物关系与剧情发展，借由角色的经历与抉择，引发玩家对人性、意识、自我的思考。

### 核心探讨
- 机器人能否产生真正的自我意识与觉醒
- 人类与仿生人之间的本质区别
- 选择带来的不同命运与多分支结局

### 游戏特点
- 多分支多结局剧情，你的选择决定故事走向
- 剧情内嵌小游戏，丰富叙事体验
- 深度思辨向主题，探讨意识、人性与仿生人的命题
- 当前版本制作较为简陋，体验尚有打磨空间
